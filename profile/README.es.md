## Sobre DataDike

**DataDike** es una empresa de software de ciberseguridad. Nuestra plataforma protege los tres puntos donde empieza la mayoría de los incidentes: **el acceso privilegiado**, **los endpoints** y **las vulnerabilidades sin corregir**.

Trabajamos para **gobiernos, organizaciones de defensa, empresas con infraestructura crítica** y los **proveedores de servicios (MSPs/MSSPs)** que las atienden.

## Nuestros Productos

### DataDike PAM — Gestión de Acceso Privilegiado

**DataDike PAM** ofrece a los equipos de DevOps, TI, negocio y operaciones acceso seguro y bajo demanda a:

- **SSH, RDP, VNC y Telnet** — acceso remoto directamente desde el navegador
- **Kubernetes** — gestión del acceso a clústeres
- **Bases de datos** — acceso monitoreado (MS SQL, Oracle, MySQL, PostgreSQL, MongoDB)
- **Aplicaciones remotas** — acceso controlado a aplicaciones críticas
- **Consolas en la nube** — Azure, AWS y GCP

| Funcionalidad | Descripción |
|---------------|-------------|
| **Gestión de Acceso Privilegiado** | Protección y monitoreo de cuentas privilegiadas |
| **Control de acceso basado en roles (RBAC)** | Permisos por rol para reducir accesos no autorizados |
| **Monitoreo y grabación de sesiones** | Seguimiento en tiempo real y grabación de sesiones privilegiadas |
| **Bloqueo de comandos** | Bloqueo de comandos peligrosos, con soporte para regex |
| **Acceso Just-in-Time (JIT)** | Acceso privilegiado temporal con revocación automática |
| **Rotación de contraseñas** | Rotación automática de credenciales en los activos gestionados |
| **Autenticación multifactor (MFA)** | Una capa adicional en cada acceso |
| **Zero Trust** | Nunca confiar, siempre verificar |
| **Cumplimiento** | Soporte para SOX, PCI-DSS, LGPD, GDPR e ISO 27001 |

### SONAR UEM Protection — Gestión Unificada de Endpoints

**SONAR UEM Protection** gestiona y protege estaciones de trabajo y servidores desde una sola consola, con un agente ligero para Windows, Linux y macOS.

| Funcionalidad | Descripción |
|---------------|-------------|
| **Inventario** | Hardware, software y ubicación de cada dispositivo |
| **Monitoreo y alertas** | Verificaciones de estado, alertas e informes |
| **Gestión de parches** | Actualizaciones de Windows por severidad, en oleadas, con control de reinicio |
| **Distribución de software** | Instalación masiva y software obligatorio por política |
| **Políticas de configuración** | Configuraciones de Windows aplicadas y mantenidas automáticamente |
| **Acceso remoto** | Soporte remoto seguro con políticas detalladas |
| **Postura de seguridad** | Puntuación por dispositivo alineada con NIST CSF, ISO 27001, SOC 2 y PCI DSS |
| **Protección de datos (DLP)** | Visibilidad y control sobre datos sensibles y medios extraíbles |
| **Multi-cliente** | Pensado para proveedores de servicios, con aislamiento por cliente y marca propia |

### CVESafe — Análisis de Vulnerabilidades

**CVESafe** encuentra y prioriza vulnerabilidades antes que los atacantes.

- **Escaneo de vulnerabilidades** en redes, servidores y aplicaciones
- **Pentest automatizado** para confirmar lo que realmente es explotable
- **Informes priorizados** con orientación clara de corrección
- **Multi-cliente** para MSPs y MSSPs que atienden a muchos clientes
