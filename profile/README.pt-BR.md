## Sobre a DataDike

A **DataDike** é uma empresa de software de cibersegurança. Nossa plataforma protege os três pontos onde a maioria dos incidentes começa: **acesso privilegiado**, **endpoints** e **vulnerabilidades sem correção**.

Atendemos **governos, organizações de defesa, empresas com infraestrutura crítica** e os **provedores de serviço (MSPs/MSSPs)** que cuidam delas.

## Nossos Produtos

### DataDike PAM — Gestão de Acesso Privilegiado

O **DataDike PAM** dá às equipes de DevOps, TI, negócio e operações acesso seguro e sob demanda a:

- **SSH, RDP, VNC e Telnet** — acesso remoto direto pelo navegador
- **Kubernetes** — gestão de acesso a clusters
- **Bancos de dados** — acesso monitorado (MS SQL, Oracle, MySQL, PostgreSQL, MongoDB)
- **Aplicações remotas** — acesso controlado a aplicações críticas
- **Consoles de nuvem** — Azure, AWS e GCP

| Recurso | Descrição |
|---------|-----------|
| **Gestão de Acesso Privilegiado** | Proteção e monitoramento de contas privilegiadas |
| **Controle de acesso por perfil (RBAC)** | Permissões por função para reduzir acessos indevidos |
| **Monitoramento e gravação de sessões** | Acompanhamento em tempo real e gravação das sessões privilegiadas |
| **Bloqueio de comandos** | Bloqueio de comandos perigosos, com suporte a regex |
| **Acesso Just-in-Time (JIT)** | Acesso privilegiado temporário com revogação automática |
| **Rotação de senhas** | Troca automática de credenciais nos ativos gerenciados |
| **Autenticação multifator (MFA)** | Uma camada extra em todo acesso |
| **Zero Trust** | Nunca confiar, sempre verificar |
| **Conformidade** | Apoio a SOX, PCI-DSS, LGPD, GDPR e ISO 27001 |

### SONAR UEM Protection — Gestão Unificada de Endpoints

O **SONAR UEM Protection** gerencia e protege estações e servidores em um só console, com um agente leve para Windows, Linux e macOS.

| Recurso | Descrição |
|---------|-----------|
| **Inventário** | Hardware, software e localização de cada dispositivo |
| **Monitoramento e alertas** | Verificações de saúde, alertas e relatórios |
| **Gestão de atualizações** | Atualizações do Windows por severidade, em ondas, com controle de reinício |
| **Distribuição de software** | Instalação em massa e programas obrigatórios por política |
| **Políticas de configuração** | Configurações do Windows aplicadas e mantidas automaticamente |
| **Acesso remoto** | Suporte remoto seguro com políticas detalhadas |
| **Postura de segurança** | Nota por dispositivo alinhada a NIST CSF, ISO 27001, SOC 2 e PCI DSS |
| **Proteção de dados (DLP)** | Visibilidade e controle sobre dados sensíveis e mídias removíveis |
| **Multi-cliente** | Feito para provedores de serviço, com isolamento por cliente e marca própria |

### CVESafe — Análise de Vulnerabilidades

O **CVESafe** encontra e prioriza vulnerabilidades antes dos atacantes.

- **Varredura de vulnerabilidades** em redes, servidores e aplicações
- **Pentest automatizado** para confirmar o que é realmente explorável
- **Relatórios priorizados** com orientação clara de correção
- **Multi-cliente** para MSPs e MSSPs que atendem muitos clientes
