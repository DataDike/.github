## About DataDike

**DataDike** is a cybersecurity software company. Our platform protects the three places where most incidents start: **privileged access**, **endpoints** and **unpatched vulnerabilities**.

We build for **governments, defense organizations, enterprises with critical infrastructure** and the **service providers (MSPs/MSSPs)** that look after them.

## Our Products

### DataDike PAM — Privileged Access Management

**DataDike PAM** gives DevOps, IT, business and operations teams secure, on-demand access to:

- **SSH, RDP, VNC and Telnet** — remote access straight from the web browser
- **Kubernetes** — cluster access management
- **Databases** — monitored access (MS SQL, Oracle, MySQL, PostgreSQL, MongoDB)
- **Remote applications** — controlled access to critical applications
- **Cloud consoles** — Azure, AWS and GCP

| Feature | Description |
|---------|-------------|
| **Privileged Access Management** | Protection and monitoring of privileged accounts |
| **Role-Based Access Control (RBAC)** | Permissions by role to minimize unauthorized access |
| **Session monitoring and recording** | Real-time tracking and recording of privileged sessions |
| **Command blocking** | Block dangerous commands, with regex support |
| **Just-in-Time access (JIT)** | Temporary privileged access with automatic revocation |
| **Password rotation** | Automated credential rotation across managed assets |
| **Multi-Factor Authentication (MFA)** | An extra layer on every access |
| **Zero Trust** | Never trust, always verify |
| **Compliance** | Support for SOX, PCI-DSS, LGPD, GDPR and ISO 27001 |

### SONAR UEM Protection — Unified Endpoint Management

**SONAR UEM Protection** manages and protects every workstation and server from one console, with a lightweight agent for Windows, Linux and macOS.

| Feature | Description |
|---------|-------------|
| **Inventory** | Hardware, software and location of every device |
| **Monitoring and alerts** | Health checks, alerts and reports |
| **Patch management** | Windows updates by severity, in waves, with restart control |
| **Software deployment** | Mass deployment and required software by policy |
| **Configuration policies** | Windows settings applied and kept in place automatically |
| **Remote access** | Secure remote support with granular policies |
| **Security posture** | Score per device aligned with NIST CSF, ISO 27001, SOC 2 and PCI DSS |
| **Data protection (DLP)** | Visibility and control over sensitive data and removable media |
| **Multi-tenant** | Built for service providers, with per-client isolation and white-label |

### CVESafe — Vulnerability Analysis

**CVESafe** finds and prioritizes vulnerabilities before attackers do.

- **Vulnerability scanning** of networks, servers and applications
- **Automated penetration testing** to confirm what is really exploitable
- **Prioritized reports** with clear remediation guidance
- **Multi-tenant** for MSPs and MSSPs serving many clients
